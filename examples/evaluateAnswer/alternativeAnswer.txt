Consider each pair of indices i and j with i < j. If values[i] + values[j] equals target, return those indices. The condition i < j guarantees different items even when the values match.

def findPair(values, target):
    for firstIndex in range(len(values)):
        for secondIndex in range(firstIndex + 1, len(values)):
            if values[firstIndex] + values[secondIndex] == target:
                return [firstIndex, secondIndex]
    return None

Each distinct pair is considered once. A returned pair has the correct sum; if the search ends without a pair, no solution exists.
There are at most n(n-1)/2 pairs, so time is O(n^2) and extra space is O(1). The question does not require linear time.
Normal case: [2, 7, 11], target=9 returns [0, 1].
Duplicates: [3, 3], target=6 returns [0, 1]. Negative values: [-2, 5], target=3 returns [0, 1].
Single item: [3], target=6 returns None. Empty list: [], target=0 returns None. No pair: [1, 2], target=8 returns None.
