Câu hỏi 2 / 5: Cơ chế hoạt động của HashMap trong Java & Kỹ thuật xử lý va chạm (Collision Resolution)

assignment Yêu cầu chi tiết câu hỏi tuyển dụng:

Hãy phân tích tường minh kiến trúc bên dưới của java.util.HashMap (từ Java 8 trở lên):

  • Cấu trúc mảng bucket Node<K,V>[] table và thuật toán phân bố bucket (n - 1) & hash.
  • Hợp đồng giữa hai phương thức cốt lõi hashCode() và equals() trong việc truy xuất dữ liệu put() / get().
  • Chiến lược giải quyết xung đột (Separate Chaining) và ngưỡng chuyển đổi sang cây đỏ đen (TREEIFY_THRESHOLD = 8, UNTREEIFY_THRESHOLD = 6, mảng >= 64).
  • Đánh giá độ phức tạp thời gian O(1) vs O(log N) và đánh đổi bộ nhớ (Memory Overhead) của TreeNode.
