Giải thích cơ chế phân phối Bucket của Java HashMap và chiến lược giải quyết xung đột khi số phần tử đạt Threshold.

Yêu cầu: Không viết mã nguồn. Trình bày qua 3 luận điểm: (1) Phép biến đổi Hashcode sang Index mảng, (2) Sự khác biệt giữa LinkedList và Red-Black Tree khi Collision vượt ngưỡng 8, (3) Đánh đổi hiệu năng (Time/Space Complexity).

Luận điểm 1: Indexation

Sử dụng phép bitwise (n - 1) & hash thay thế phép chia lấy dư modulo để đạt O(1) CPU cycle.

Luận điểm 2: Treeify

Chuyển hoá LinkedList thành Red-Black Tree khi bucket ≥ 8 và capacity ≥ 64 nhằm hạ độ phức tạp dò tìm từ O(n) xuống O(log n).

Luận điểm 3: Trade-off

Chi phí cấp phát con trỏ TreeNode gấp đôi Node thường, chỉ kích hoạt khi phân bố hashing bị lệch nghiêm trọng.
